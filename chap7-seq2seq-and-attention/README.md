# Seq2Seq 序列逆置实验记录

## 1. 实验目标
本实验的目标是完成字符序列逆置任务（sequence reversal），并对比：
- 不带注意力机制的 Seq2Seq
- 带注意力机制的 Seq2Seq

任务形式为：输入一个大写字母序列，输出其反转序列。

## 2. 过程与问题（心路历程）
最开始我基于原始的 TensorFlow notebook 继续修改与调试，想直接在原工程上完成实验。

但在实际运行中遇到一个核心问题：  
由于 TensorFlow 版本更新，原文件中的部分函数调用方式、`call` 参数传递方式和图执行相关写法在新语法下不再稳定，训练阶段反复出现“无梯度”或梯度无法正确回传的问题，导致模型难以正常优化。

我尝试过修补 notebook（包括初始化、输入传递、训练调用等），但为了确保实验目标按时、可复现地达成，最终决定切换到 PyTorch 重新实现同一任务。

## 3. 最终实现方案
在当前目录中完成了两份 PyTorch 实现：
- `sr_torch.py`：不带注意力机制的 Seq2Seq（GRU Encoder-Decoder）
- `sr_attn_torch.py`：带双线性注意力机制的 Seq2Seq（GRU + Bilinear Attention）

两份代码均包含：
- 随机样本生成（大写字母序列）
- 训练流程（teacher forcing）
- 自回归解码（逐步生成）
- 逆置正确性检验（预测结果是否等于输入反转）

## 4. 实验现象与结果
在当前实验设置下（按脚本默认/推荐参数训练后）：
- 无注意力模型：测试 16 条样本，`0/16` 正确
- 有注意力模型：测试 16 条样本，`15/16` 正确

这个结果说明：  
对于序列逆置任务，注意力机制显著改善了解码阶段对输入信息的利用能力，效果明显优于不带注意力的基础 Seq2Seq。

## 5. 运行方式
### 无注意力版本
```bash
python sr_torch.py
```

### 注意力版本
```bash
python sr_attn_torch.py
```

若希望更稳定收敛，可适当提高训练轮次，例如：
```bash
python sr_attn_torch.py --steps 4000 --batch-size 64 --lr 3e-4
```

## 6. 总结
这次实验最大的收获不是“代码一次跑通”，而是面对框架版本差异时，能够快速定位核心阻塞（梯度传递失效），并在可控时间内切换实现路径，保证实验目标完成。  
最终结果也验证了注意力机制在序列建模任务中的实际价值。
